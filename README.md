### Objetivo:
Favorecer ao aluno a compreensão de aspectos avançados do paradigma de
desenvolvimento de software orientado a objetos. Realizar a implementação
destes conceitos em uma linguagem de programação.

### Ementa:
- Conceitos de Interfaces
- Classes Abstratas
- Membros Estáticos e Membros finais
- Pacotes. 
- Conceitos e aplicação de meta programação e reflexão. 
- Conceitos e Uso de Coleções
- Mapeamento Objeto-Relacional
- Acesso a banco de dados.
- Tipos genéricos e tipos enumerados.
